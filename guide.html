1. สำหรับสมาชิก — วิธีเช็คอิน

  1. เปิด LINE แล้วเข้าโหมดสแกน QR code (หรือใช้กล้องมือถือ) สแกน QR ที่หน้างาน
  2. กด “อนุญาต” ให้ใช้ตำแหน่ง (ต้องอยู่ในรัศมี 1 กม. จากศูนย์ประชุม)
  3. ครั้งแรกเท่านั้น เลือกชื่อตัวเองแล้วกดยืนยัน ชื่อจะผูกกับมือถือเครื่องนั้น
  4. ครั้งต่อไปสแกนแล้วเช็คอินทันที ไม่ต้องเลือกชื่ออีก
ช่วงเวลาผล
05:00 – 07:00 น. (และก่อนกดเปิดประชุม)ตรงเวลา
หลัง 07:00 น. หรือหลังผู้ดูแลกด “เปิดประชุม” (อย่างใดถึงก่อน)มาสาย พร้อมจำนวนนาที
ไม่สแกนจนถึง 08:00 น.ขาดประชุม

เช็คอินแทนกันไม่ได้: มือถือ 1 เครื่องผูกได้ 1 ชื่อ และต้องอยู่ที่ศูนย์ประชุมจริง ถ้าเปลี่ยนมือถือให้แจ้งผู้ดูแลกด “รีเซ็ตมือถือ”

2. ผู้ดูแล — เริ่มใช้ครั้งแรก (ทำครั้งเดียว)

  1. เปิด หน้าผู้ดูแล ตั้งชื่อผู้ใช้และรหัสผ่านของผู้ดูแลหลัก (คนแรกที่ตั้งจะเป็นผู้ดูแลหลัก)
  2. แท็บ สมาชิก ตรวจรายชื่อ เพิ่มคนที่ขาดด้วยปุ่ม “+ เพิ่มสมาชิก”
  3. แท็บ ตั้งค่า / QR / LINE ตรวจเวลาและตำแหน่ง แล้วกด “พิมพ์ QR” ไปติดที่หน้างาน (หรือเปิด หน้า QR ขึ้นจอ)
  4. ตั้งค่า LINE ตามหัวข้อ 6 และแก้ข้อความจดหมายเตือนตามหัวข้อ 7
  5. ถ้ามีผู้ช่วย เพิ่มผู้ดูแลคนอื่นได้ในหัวข้อ “ผู้ดูแลระบบ” ท้ายแท็บตั้งค่า

3. ผู้ดูแล — ขั้นตอนวันประชุม

  1. 05:00 น. ระบบเปิดรับสแกนเอง ไม่ต้องทำอะไร
  2. เปิดหน้าผู้ดูแล แท็บ วันนี้ จะเห็นรายชื่อคนเช็คอินสด ๆ และ 3 อันดับมาเช้าสุด
  3. เมื่อเริ่มประชุม กดปุ่มเขียว “▶ เปิดประชุม” คนที่สแกนหลังจากนี้นับเป็นมาสาย (ถ้าไม่กด ระบบตัดสายที่ 07:00 น. เอง)
  4. ใครแจ้งลา ให้เลือกชื่อในรายการ “ยังไม่เช็คอิน” แล้วบันทึกเป็น ลา ก่อน 08:00 น.
  5. 08:00 น. ระบบปิดรอบเอง คนที่ไม่สแกนถูกบันทึกเป็นขาด แล้วส่งรายงานพร้อมจดหมายเตือนเข้ากลุ่ม LINE

ประชุมนอกวันศุกร์หรืออยากทดสอบ: กด “สร้างรอบพิเศษวันนี้” รอบพิเศษไม่ปิดเอง ต้องกด “ปิดรอบและส่งรายงานตอนนี้” ถ้าเป็นรอบทดสอบให้กด “ลบรอบนี้” เพื่อไม่ให้นับสถิติ

4. การแก้ไขข้อมูล

ต้องการทำที่ไหน
แก้สถานะของวันนี้ (ตรงเวลา / สาย / ขาด / ลา)แท็บวันนี้ → ช่อง “แก้ไข” ท้ายแถวของคนนั้น
แก้รอบย้อนหลังแท็บประวัติ → “ดู / แก้ไข”
แก้ยอดสะสม สาย / ขาด / ลา / คะแนน ของแต่ละคนแท็บสมาชิก → “แก้ข้อมูล” พิมพ์ตัวเลขใหม่แล้วบันทึก
สมาชิกเปลี่ยนมือถือ หรือเลือกชื่อผิดแท็บสมาชิก → แก้ข้อมูล → “รีเซ็ตมือถือ”
สมาชิกลาออกแก้ข้อมูล → เอาเครื่องหมาย “ยังเป็นสมาชิกอยู่” ออก (ประวัติยังอยู่)
อัปเดตคะแนน BNI Traffic Lightsแท็บสมาชิก → “นำเข้าคะแนน BNI” คัดลอกตารางจาก Reporting2You มาวาง (เดือนละครั้ง)
เริ่มนับรอบใหม่ (เทอมใหม่)แท็บตั้งค่า → “เริ่มนับสะสมตั้งแต่วันที่”

5. กติกาและความหมายของสี

  • มาสาย 5 ครั้ง = ขาด 1 ครั้ง
  • ขาดรวม (ขาดจริง + ขาดจากสาย) ครบ 3 ครั้ง = โทษร้ายแรงที่สุด
  • ลา ไม่นับเป็นขาด แต่ถูกนับจำนวนครั้งไว้
  • วันที่ไม่มีใครเช็คอินเลย ระบบถือว่างดประชุม ไม่นับขาด

6. ตั้งค่า LINE ผู้ช่วยส่งรายงาน (ทำครั้งเดียว)

ใช้บัญชี LINE Official Account (LINE OA) เป็นผู้ช่วยส่งข้อความเข้ากลุ่ม บัญชี LINE ส่วนตัวใช้ส่งอัตโนมัติไม่ได้

  1. เข้า manager.line.biz เลือกบัญชี LINE OA ที่จะใช้ (หรือสร้างใหม่ ฟรี) → ตั้งค่า → Messaging API → กดเปิดใช้งาน
  2. เข้า developers.line.biz → เลือก Channel ของบัญชีนั้น → แท็บ Basic settings คัดลอก Channel secret
  3. แท็บ Messaging API เลื่อนลงล่างสุด กด Issue ที่ Channel access token แล้วคัดลอก
  4. กลับมาหน้าผู้ดูแล แท็บตั้งค่า หัวข้อ “แจ้งเตือน LINE กลุ่ม” วางทั้งสองค่า แล้วกด “บันทึก LINE”
  5. ที่แท็บ Messaging API ตั้ง Webhook URL ตามที่หน้าผู้ดูแลแสดง แล้วเปิด Use webhook
  6. ที่ manager.line.biz → ตั้งค่า → ตั้งค่าบัญชี เปิด “อนุญาตให้เข้าร่วมกลุ่ม” แล้วเชิญ LINE OA เข้ากลุ่มของชาพเตอร์
  7. พิมพ์ ลงทะเบียนกลุ่ม ในกลุ่ม บอทจะตอบยืนยัน จากนั้นกด “ส่งข้อความทดสอบ” ในหน้าผู้ดูแล

โควตาข้อความ: แพ็กเกจฟรีของ LINE OA มีจำนวนข้อความต่อเดือนจำกัด และการส่งเข้ากลุ่มนับตามจำนวนคนในกลุ่ม ระบบจึงรวมรายงานกับจดหมายเตือนไว้ในการส่งครั้งเดียวต่อสัปดาห์ กรุณาตรวจโควตาปัจจุบันในหน้า manager.line.biz

7. จดหมายเตือนขาดประชุม

  • มี 3 ฉบับ ข้อความต่างกัน: ฉบับที่ 1 เมื่อขาดรวม 1 ครั้ง · ฉบับที่ 2 เมื่อขาดรวม 2 ครั้ง · ฉบับที่ 3 เมื่อขาดรวม 3 ครั้งขึ้นไป
  • ระบบออกให้อัตโนมัติตอนปิดรอบ เฉพาะคนที่ยอดขาดรวมขยับขึ้นในรอบนั้น (ขาด หรือสายครบ 5 ครั้ง) และส่งเข้ากลุ่มพร้อมรายงาน
  • แต่ละฉบับออกครั้งเดียวต่อคน ไม่ส่งซ้ำทุกสัปดาห์
  • แก้ข้อความได้ที่แท็บตั้งค่า หัวข้อ “จดหมายเตือนขาดประชุม” ใช้คำในวงเล็บปีกกาให้ระบบเติมข้อมูล เช่น {ชื่อ} {ครั้ง} {ขาด} {สาย} {เกณฑ์} {วันที่} {ชื่อประชุม}
  • ในหัวข้อเดียวกันมีรายการ “จดหมายที่ออกแล้ว” กดอ่าน ส่งอีกครั้ง หรือลบได้ และปิดการส่งอัตโนมัติได้ด้วยช่องติ๊ก
  • ถ้าแก้สถานะจากขาดเป็นลาก่อนส่ง จดหมายฉบับนั้นจะถูกยกเลิกเอง

จดหมายถูกส่งเข้ากลุ่ม สมาชิกทุกคนจะเห็น ถ้าต้องการแจ้งเป็นการส่วนตัว ให้ปิดการส่งอัตโนมัติ แล้วกด “อ่าน” เพื่อคัดลอกข้อความไปส่งเอง

9. ปัญหาที่พบบ่อย

อาการวิธีแก้
ขึ้น “อยู่นอกพื้นที่ประชุม”อยู่ไกลเกิน 1 กม. หรือ GPS ยังไม่นิ่ง ให้เปิด GPS ออกมาที่โล่ง แล้วกดลองใหม่
ไม่ขึ้นหน้าต่างขออนุญาตตำแหน่งเปิดการเข้าถึงตำแหน่งให้เบราว์เซอร์ในตั้งค่ามือถือ แล้วสแกนใหม่
ขึ้นว่าชื่อนี้ผูกกับเครื่องอื่นแล้วผู้ดูแลกด “รีเซ็ตมือถือ” ของชื่อนั้น แล้วให้สแกนใหม่
มือถือแบตหมด / ลืมมือถือผู้ดูแลบันทึกสถานะแทนในแท็บวันนี้
รายงานไม่เข้ากลุ่ม LINEดูสถานะ Token / Secret / กลุ่ม ในแท็บตั้งค่า ต้องเป็น ✅ ทั้งสาม แล้วกด “ส่งข้อความทดสอบ” ถ้าโควตาข้อความของเดือนหมด LINE จะไม่ส่งให้
